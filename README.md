# 🏡 Real Estate Platform

A modern **full-stack Real Estate web application** built to simplify the process of buying, selling, and renting properties. The platform provides an intuitive interface for users to browse listings, manage properties, authenticate securely, and connect with property owners through a responsive and user-friendly experience.

# 📖 Overview

The Real Estate Platform is a MERN Stack application designed to provide a seamless property browsing and management experience. Users can securely register, explore available properties, search using filters, manage listings, and maintain their profiles.

The project follows a modular architecture with separate frontend and backend applications, making it scalable and easy to maintain.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/mohdshiyab/Real-Estate-Project-Internship-.git
```

---

### Navigate to Project

```bash
cd Real-Estate-Project-Internship-
```

---

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

# ▶️ Running the Application

### Start Backend

```bash
npm run dev
```

### Start Frontend

```bash
npm run dev
```

Visit:

```
http://localhost:5173
```
